# Design & content resources for Crespidia

## Primary visual reference (final decision)

- **La Croissanterie** — [Loyalty presentation](https://www.lacroissanterie.fr/votre-espace-fidelite/presentation/)
- Brand site: [https://www.lacroissanterie.fr/](https://www.lacroissanterie.fr/)
- Theme CSS: `https://www.lacroissanterie.fr/wp-content/themes/lacroissanterie/main.css`

### Tokens taken from La Croissanterie

| Token | Value | Use |
|-------|--------|-----|
| Orange | `#FFA300` / `#ffa301` | Primary CTA, accent |
| Yellow | `#FFD631` | Highlights, badges |
| Cream | `#FFF6E5` | Page background |
| Ink | `#07272D` / `#08272D` | Text, dark panels |
| Mist | `#f0f3f4` | Soft UI |

Tone: happy bakery, rounded CTAs, clear “how it works” loyalty steps, product-forward photography.
